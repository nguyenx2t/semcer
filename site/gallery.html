Same CER, different damage

Each card shows two real systems that made the same number of errors on the same line, so their CER is identical. semCER tells them apart. Hover or tap an error to see what it costs.

harmlessmeaning lost

Turn on “See it as CER does” and every error looks the same. Scores come from the released scorer (semcer 0.1.5, fp32), so pip install semcer gives the same numbers. Lines come from the sources in our dataset whose licenses allow redistribution; each card names its source and license.
